# 既存の文書を書き直すとき

1. 元の文書から事実だけを抜き出してメモにする。メモは「項目: 値」か短い断片で書いて、元の見出しと順番は使わない。比喩や言い回しは捨てて、起きる現象を平らな語で書く。コード例、コマンド、パス、数値は元のまま転記する。
2. メモの各項目に `SKILL.md` の 1 節の選別を適用する。
3. `SKILL.md` の 2 節に従って、見出しの名前と順番、各見出しに入れるメモの項目を決める。これを骨組みと呼ぶ。骨組みは文を書く前に確定して、書いている途中で変えない。メモの区分をそのまま見出しにしない。
4. 元の文書を見ないで骨組みとメモから文を書く。

元の文書に無い事実は足さない。誤記に見える日付や数値も元のまま残して、依頼者への報告で指摘する。

人が書いた文書を調子の見本にするなら、その文書は骨組みを確定した後に読んで、1 文ごとの調子だけを借りる。口語の言い回しは借りない。
