# ja-reports-and-docs

Claude Code で日本語の報告や文書を出力させる際に使用する skill です。
Claude からの報告・出力された日本語の文章を自然な形に修正します。

README、commit メッセージ、調査報告等の出力時に使用する想定としています。

## 修正の例

| 修正する点 | 修正前 | 修正後 |
|---|---|---|
| 読み手に必要な情報だけにする | 件数が多いと、収集に数分かかります。収集中はスクロール操作をせず、タブを表示したままにしてください。X は表示されていないタブでは次のページを読み込まないので、別のタブに切り替えると収集が進みません。 | 件数が多い場合は数分かかりますが、収集中はブラウザの操作をしないでください。 |
| 書き手の事情を読み手に必要な情報にする | 作者の環境は Windows 11 と Python 3.12 | Windows 11 と Python 3.12 の組み合わせで動作を確認している |
| 意味の広い語を狭い語にする | CLI を起こして命令を送る | CLI を起動して命令を送信する |

## 動作

対象の文書を書く場面で Claude Code が自動で読み込みます。

| 書く文書 | 載せる情報を選ぶ | 文を直す | 別の Claude が不要な文を削る | 言い回しを検索して直す | 別の Claude が初見で読んで確認する |
|---|:-:|:-:|:-:|:-:|:-:|
| セッション内の調査報告 | ◯ | ◯ | | | |
| まとめ資料、設計メモ | ◯ | ◯ | ◯ | ◯ | |
| commit メッセージ | | ◯ | | ◯ | |
| README、手順書、PR の説明 | ◯ | ◯ | ◯ | ◯ | ◯ |

README、手順書、PR の説明では別の Claude を 2 回起動するので、その分の時間とトークンが掛かります。作者の環境では 1 回あたり 20〜60 秒でした。

短い受け答えには、応答が遅くなるため適用していません。

## インストール

このリポジトリを `~/.claude/skills/ja-reports-and-docs/` に配置してください。使用をやめる場合はこのフォルダを削除します。

読み込まれないことがある場合は、`~/.claude/CLAUDE.md` に次の 1 行を追加してください。

```
調査結果の報告、まとまった説明、まとめ資料、README、commit、PR、手順書を書くときは `ja-reports-and-docs` skill に従う。
```

## 検証の状況

既存の README を 2 本書き直して、直す前と後を別々の Claude に読ませて、読んでいて止まった箇所を数えました。

| 文書 | 行数 | 止まった箇所 | 最初の手順までの行数 |
|---|--:|--:|--:|
| 書いたまま手を入れていなかった README | 155 → 82 | 25 → 17 | 44 → 14 |
| 作者が何度か直した後の README | 110 → 101 | 14 → 12 | 35 → 32 |

直した後に残った箇所の多くは、元の文書に書かれていなかった情報の不足です。この skill は元の文書に無い事実を足さないので、不足は依頼者への確認事項として報告されます。

読ませたのは 1 回ずつなので、数件の差は誤差の範囲です。人が読んで比べた評価はまだありません。
